- 150+ animated components (marquees, beams, globes, text effects, etc.)
- Pro: 50+ marketing page sections + 9+ full templates
- Same copy-into-repo / registry model as shadcn

### Notable differentiators
- Brand = motion candy; strong YouTube/Twitter meme surface
- Clear free vs Pro split (components free, composed sections paid)

### Gaps vs AtroUI
- No Host API / BYOK server story
- Taste skews high-motion / “AI landing” atmosphere (glow, beams) — opposite of AtroUI soft-rect / anti-slop rule
- Pro license forbids reselling/redistributing code (AtroUI MIT catalog is freer for remix)
