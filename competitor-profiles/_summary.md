### Interpretation
- Magic & Aceternity own the **paid spectacle section** quadrant.

## Competitive SWOT (AtroUI)

**Strengths**
- Official `@atroui` directory namespace; dual shadcn + `@atroui/cli` + MCP
- Host APIs with BYOK (rare among kits)
- Live rooms that match installables
- Locked taste (soft-rect / Family Values) vs AI-slop cluster

**Weaknesses**
- Brand/SEO/backlink scale far behind Magic/Aceternity/shadcn
- Free-first means no Pro ARPU yet
- Catalog breadth still catching animation kits on “wow” demos

**Opportunities**
- Tailwind Plus closed → displaced buyers
- Agent/MCP wave: install truth + for-agents playbook
- Compare SEO: “Aceternity alternative”, “Magic UI alternative” with honest battle cards
- Host API as category language AtroUI can own

**Threats**
- Aceternity/Magic deepen free sections or Host-like stubs
- coss “atoms” blur API-connected UI story
- Taste exhaustion: market rewards fireworks AtroUI refuses
