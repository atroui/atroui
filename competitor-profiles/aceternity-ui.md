## Positioning & Messaging

**Primary value proposition**: Production-ready landing components/blocks/templates for React + Tailwind + Motion; copy-paste or agent-install.

**Target audience**: Founders and design engineers shipping marketing sites / AI SaaS landings fast.

**Positioning angle**: “Beautiful landing pages” — hero/shader/bento heavy. Distribution-by-source like shadcn.

**Key messaging themes** (homepage):
- Used by companies / founders social proof
- Free components + Pro blocks
- Tell your agent to build the website (MCP)

## Product & Features

### Core capabilities
- Free: 3D cards, marquees, background beams, hero highlights, etc.
- Pro: heroes, features, pricing, navbars, testimonials, shaders, full templates
- Registry auth via `ACETERNITY_PRO_TOKEN` for Pro items

### Notable differentiators
- Strong Pro block volume and template SKUs
- Mature agent/MCP + prompt story
- High visual polish / micro-interaction brand

### Gaps vs AtroUI
- No Host API BYOK product line (forms/AI routes as first-class)
- Aesthetic = premium motion landings (often capsule/glow adjacent) vs AtroUI dark-first soft-rect rooms
- Paid wall on most production sections; AtroUI keeps catalog MIT/free-first
- Live “rooms” that match install (Launch / Theme Studio) not their core story — they sell preview + Pro download

## Strengths / Weaknesses

**Strong**: Category leader for “pretty Next landings”; agent install; clear monetization; social proof volume.

**Weak for AtroUI ICP**: Paywall on sections; taste cluster overlaps AI-slop risk; no owned Host API security story; Pro token friction.
