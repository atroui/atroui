## Positioning & Messaging

**Primary value proposition**: Composable, accessible components with thoughtful defaults — build *your own* library with code you own.

**Target audience**: Teams building design systems and app UI in React.

**Positioning angle**: Foundation, not a finished marketing kit. Ecosystem host for `@namespace` registries (including `@atroui`).

## Product & Features

- Accessible primitives (Base UI / Radix era continuum)
- CLI init/add/diff, `components.json`, official registries.json
- Docs, examples, MCP/agent surface evolving with the ecosystem

### Gaps (by design)
- Does not optimize for production marketing *sections* or Host APIs
- Leaves taste and block altitude to registries like Magic, Aceternity, AtroUI
