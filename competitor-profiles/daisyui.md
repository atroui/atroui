## Positioning & Messaging

**Primary value proposition**: Write fewer Tailwind classes; semantic components; themes out of the box.

**Target audience**: Devs who want Bootstrap-like speed on Tailwind (often MVP / HTMX / multi-framework).

**Positioning angle**: Productivity + theme buffet — opposite of AtroUI’s “opinionated defaults, own the files, no theme soup.”

---

## Product & Features

- 68+ component class sets, 600+ utilities messaging
- Theme generator; many preset themes
- Agent skill install (`npx skills add saadeghi/daisyui`)

### Gaps vs AtroUI
- Not a React section catalog; not shadcn registry
- Theme switching is the product — AtroUI explicitly rejects daisyUI-style theme soup (Axis + Companion instead)
- No Host API story

- Use as **contrast foil** in compare/migrate docs, not as a feature race.
