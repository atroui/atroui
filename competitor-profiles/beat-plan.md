# Beat plan — give Magic / Aceternity a real fight

**Generated**: 2026-10-25  
**Goal**: Not “1M visits in a quarter.” Goal: **become the default pick** when a shadcn builder wants *production sections they own* + *forms/AI on their keys* + *taste that isn’t AI-slop*. That converts to installs, GitHub stars, AI citations, and directory mindshare — then traffic follows.

**Constraint**: Free-first (product marketing). No Plus paywall until there’s a hit.

---

## How they win (so we don’t copy the wrong game)

| Their engine | Evidence | Don’t copy blindly |
|--------------|----------|--------------------|
| Brand + Direct (~48% of visits) | Semrush | Needs time + demos + social |
| Spectacle catalog | Beams, shaders, 3D | Violates Family Values / soft-rect |
| Pro ARPU | $169–$199 | We’re free-first on purpose |
| Agent traffic | 30–64K ChatGPT visits/mo | **Do copy** — MCP + llms already started |
| Link velocity | 2K+ referring domains | PR + directories + compare pages |

**Open cell (from profiling)**: MIT sections + Host APIs + live rooms. Occupy it loudly.

---

## Strategy: three fronts

### 1. Product wedge (make switching irrational)

Ship and *demo* what they can’t match without becoming a different company:

| Wedge | Why it hurts them | Ship / tighten |
|-------|-------------------|----------------|
| **Host APIs + BYOK** | Neither Magic nor Aceternity sells hardened routes | Docs page, install matrix, one killer demo (waitlist → Resend on *your* key) |
| **Live rooms = install truth** | Their previews ≠ “same files you add” as hard | `/landing`, `/launch`, Theme Studio — stamp “same as `shadcn add @atroui/…`” everywhere |
| **Soft-rect / anti-slop** | Their brand *is* fireworks | One taste-proof landing kit; refuse glow-orb identity |
| **Dual install + MCP** | They’re good; we can be clearer | Agent chip, for-agents, MCP catalog sync — install in one paste |
| **Launch workflow** | Scope → OG is a job, not a component | Make `/launch` the shareable “wow” that isn’t a beam |

**Rule**: Never measure success as “more animated components than Magic.”

### 2. Distribution wedge (asymmetric growth)

| Channel | Play | KPI (90d) |
|---------|------|-----------|
| **AI / agents** | Strengthen `llms.txt` / `llms-full.txt`; MCP skills; “Copy for agent” on every block | Appear in ChatGPT/Perplexity answers for Host API / AtroUI queries; rising AI referrals in analytics |
| **shadcn directory** | Stay pristine; featured blocks; install commands only registry-first | `@atroui` installs (proxy: registry hits if logged) |
| **Compare / alternatives SEO** | Publish AtroUI vs Aceternity, vs Magic, “alternatives” hubs | Rank for those queries; crawlable FAQ schema |
| **Founder demos** | Short clips: Theme Studio accent flip; Launch Room brief→OG; landing-kit 390 | Social shares / GH stars velocity |
| **Directories & lists** | “Best shadcn registries 2026”, Awesome lists, PH follow-up | Referring domains +1 quality/week |

### 3. Narrative wedge (own the words)

Repeat until it’s boring:

> Own the UI in your repo. Borrow the boring API security. Bring your own keys.  
> Add the section. Own the room.

Kill: “component library,” npm-first UI, “AI-powered UI kit.”
