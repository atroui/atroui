# @atroui/cli

First-party installer for the AtroUI registry. Copies component source into your repo without requiring the shadcn CLI.

```bash
# Add one or more items
npx @atroui/cli@latest add home-hero

# Interactive picker
npx @atroui/cli@latest add

# List the catalog
npx @atroui/cli@latest list
```

Registry: https://www.atroui.com/r/{name}.json

The shadcn CLI path remains supported. See https://www.atroui.com/docs/installation
