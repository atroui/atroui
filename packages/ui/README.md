# atroui

**[AtroUI](https://atroui.com)** - production React / Next.js component catalog. Add components with the shadcn CLI:

```bash
npx shadcn@latest init
npx shadcn@latest registry add @atroui=https://www.atroui.com/r/{name}.json
npx shadcn@latest add @atroui/home-hero
```

Docs: [atroui.com/docs/installation](https://www.atroui.com/docs/installation) · Registry: [atroui.com/docs/registry](https://www.atroui.com/docs/registry)
